# Logan 语录 · Gemini 负责人发言集

抓取 Logan（Google Gemini 项目负责人，[@OfficialLoganK](https://x.com/OfficialLoganK)）在 X 上的发言与回复，经浏览器翻译后截图保存，按用途分类整理。

## 在线搜索

网页端：[https://nullaqua.github.io/Logan/](https://nullaqua.github.io/Logan/)

支持模糊搜索、分类筛选，中英文符号（：与 :）通用。

## 分类

| 分类 | 说明 |
|------|------|
| 斗图 | 简短通用、可日常代用的发言（「太棒了！」「哈哈」「喜欢它」） |
| 嘉豪 | 说得有道理、有逼格的句子 |
| 工作 | 发布预告、画饼、模型产品介绍、客服式回复 |
| 无意义 | 单个 emoji、单词、无上下文的感叹 |

## 目录结构

- `斗图/`、`嘉豪/`、`工作/`、`无意义/`：分类图片
- `data.json`：网页搜索用的数据索引
- `index.html`：前端页面
- `Temp/`：新抓取图片的暂存区，整理时归入上述分类

## 数据维护

新图放入 `Temp/` 后运行 `scripts/` 中的整理脚本（TODO），或手动移动到对应分类文件夹，然后重新生成 `data.json`。
